1. Get the usage from the customer

An admin pastes this prompt into their analytics chat (or, for AWS Bedrock, runs one command in AWS CloudShell) and sends you the answer. Use one per provider.

  1. Open .
  2. Paste this command and press Enter:
  3. Download the CSV file(s) it names (Actions > Download file) and add them in step 2.

Alternative: paste the script yourself

Save it as bedrock_usage.py in CloudShell and run python3 bedrock_usage.py. Big pastes can get cut off there, so check that the file's last line is main().

Paste what the chat returned, or drop the .csv files here, including the CSVs claude.ai's
          analytics chat lets you download (drop all of them; overlapping ones aren't double-counted) and Claude
          Console usage exports. Add as many providers as you like.

Opens the Usage, On-prem sizing and Grafana tabs. You can come back here to add more data
