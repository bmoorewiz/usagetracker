1. Get the usage from the customer

An admin pastes this prompt into their analytics chat and sends you the answer. Use one prompt per provider.


        
        
      


      

        
2. Add the answers

        
Paste what the chat returned, or drop the .csv files here, including the CSVs claude.ai's
          analytics chat lets you download (drop all of them; overlapping ones aren't double-counted) and Claude
          Console usage exports. Add as many providers as you like.

        
        

          
          
        

        

        

      


      

        
3. Build the report

        
Opens the Usage, On-prem sizing and Grafana tabs. You can come back here to add more data
          and rebuild.

        

          
          
        

        
Everything runs in this browser. The customer's data isn't uploaded anywhere.
