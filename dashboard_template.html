How this is worked out

    Put this report in Grafana

    The dashboard carries its own data, so nothing else needs to be set up besides the free Infinity plugin.

    Easiest: in the Frontier Usage app, fill in your Grafana address and a service-account token under "Grafana" and click Publish to Grafana. It creates or updates this dashboard for you.

    Or import it by hand:

    1. (also saved next to this report as grafana-dashboard.json)
    2. Make sure the Infinity data source plugin is installed: Administration → Plugins, search "Infinity" (Grafana Cloud has it), or on the server: grafana-cli plugins install yesoreyeram-infinity-datasource
    3. Add an Infinity data source if you don't have one: Connections → Data sources → Add → Infinity, then Save.
    4. Dashboards → New → Import, upload the JSON, pick the Infinity data source, and click Import.

    Each report makes a fresh snapshot. Re-importing (or re-publishing) replaces the dashboard with the same name.
